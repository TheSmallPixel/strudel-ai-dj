# strudel-ai-dj

An AI-controllable DJ built on a fork of [Strudel](https://codeberg.org/uzu/strudel),
driven via the **Model Context Protocol (MCP)**.

Strudel is the instrument. An LLM (Claude, or any MCP client) is the second
pair of hands — writing patterns, mixing, transitioning, and syncing to
external audio sources like Spotify in real time.

> Status: **early planning**. See [PLAN.md](./PLAN.md) for the architecture
> and phased roadmap.
